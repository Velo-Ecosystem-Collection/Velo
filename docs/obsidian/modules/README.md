# Velo Modules

These notes are organized around change ownership rather than every folder. Start with [[Repository Map]], then choose the domain note closest to the requested behavior.

- [[modules/Projects and Verification]] — project lifecycle, on-chain provenance, and roles.
- [[modules/Payments and Checkout]] — PaymentIntent API, hosted checkout, verification, and credits.
- [[modules/Webhooks]] — merchant endpoint configuration, durable delivery, signatures, and replay.
- [[modules/Settlement and PDAX]] — PDAX UAT provider and payout lifecycle.
- [[modules/Billing and Entitlements]] — promotional/paid credits, top-ups, reservations, and launch controls.
- [[modules/Playground]] — contract specs, simulation, XDR review, Testnet invocation, and history.
- [[modules/Stellar Transactions and Contract Events]] — transaction cache, RPC confirmation, and event polling.
- [[modules/Wallet Authentication]] — Stellar wallet connection and Convex JWT auth.
- [[modules/Observability]] — correlation, telemetry outbox, journey stages, and local stack.
- [[modules/SDK and Wallets]] — public Node SDK and project-configured wallet package.
